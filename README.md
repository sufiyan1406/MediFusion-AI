## 🩺 What is MediFusion?

MediFusion is a computer-vision and deep-learning project that analyzes chest X-ray images for potential abnormalities.

Instead of producing a binary "normal / abnormal" output, the system performs **multi-label classification**, allowing a single X-ray to receive predictions for multiple possible findings.

The model produces:

- Probability scores for 14 abnormalities
- Per-class decision thresholds
- Threshold-based predicted findings
- Deterministic inference results
- Model and checkpoint information
- Structured JSON-compatible prediction output

The project combines **model training, validation, evaluation, threshold optimization, automated testing, and a production-style inference pipeline**.

## ✨ Core Features

### 🩻 Chest X-Ray Analysis

Upload a chest X-ray image and MediFusion processes it through the trained neural network.

Supported image input:

- PNG
- JPEG
- Single chest X-ray image

---
