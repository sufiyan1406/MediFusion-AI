## 🧬 Overview

**MediFusion** is an AI-assisted chest X-ray abnormality analysis system designed to demonstrate how deep learning can be applied to multi-label medical image classification.

Instead of predicting only one disease, MediFusion analyzes a chest X-ray for **14 possible thoracic abnormalities simultaneously**.

The system combines:

- 🩻 Chest X-ray image preprocessing
- 🧠 Custom convolutional neural network
- 🎯 Multi-label classification
- ⚖️ Class-imbalance handling
- 📊 Validation-based decision thresholds
- 🧪 Official test-set evaluation
- 🚀 Production-style inference pipeline
- 🖥️ Interactive web interface

🔬 Research Objective

The main objective of MediFusion is to investigate a lightweight deep-learning approach for detecting multiple abnormalities from chest X-ray images.

The project focuses on three major challenges:

1. Multi-Label Classification

A single X-ray may contain multiple abnormalities.

For example:

Chest X-ray
     │
     ├── Effusion
     ├── Atelectasis
     └── Cardiomegaly

Therefore, the model uses independent outputs for each pathology rather than forcing the image into a single class.

2. Severe Class Imbalance

The NIH ChestX-ray14 dataset contains highly unequal numbers of positive samples across pathologies.

For example:

Infiltration     → 11,853 positive samples
Atelectasis      →  7,003
Effusion         →  7,415
Pneumonia        →    742
Hernia           →    113

To address this, MediFusion calculates class-specific positive weights from the training split only.

3. Decision Threshold Selection

Using a fixed threshold of 0.5 for every pathology is not necessarily appropriate for an imbalanced multi-label problem.

MediFusion therefore determines class-specific thresholds using the validation set and keeps those thresholds frozen during test evaluation.

MedCXRNet

⚙️ Training Pipeline
Experiment 1 — Baseline

The first experiment established the baseline MedCXRNet model.

The model was trained using the standard training pipeline and evaluated using the official validation and test splits.

Baseline Test Performance
Macro ROC-AUC : 0.6630
Macro PR-AUC  : 0.1258
⚖️ Experiment 2 — Class-Imbalance Handling

The second experiment introduced class-specific positive weights.

The weight for each class was calculated as:

pos_weight = negative_samples / positive_samples

Importantly, these values were calculated only from the training split.

Example:

Atelectasis       → 9.55
Cardiomegaly      → 49.87
Pneumonia         → 98.62
Hernia            → 653.12

The resulting weighted loss helps the training process pay greater attention to rare abnormalities.

Experiment 2 Validation
Best Epoch       : 15
Validation AUC   : 0.7073
Experiment 2 Official Test Evaluation
Macro ROC-AUC : 0.6569
Macro PR-AUC  : 0.1164
Macro Recall  : 0.7198
Macro F1      : 0.1676
📊 Experimental Results
Baseline vs Class-Weighted Training
Metric	Experiment 1	Experiment 2
Macro ROC-AUC	0.6630	0.6569
Macro PR-AUC	0.1258	0.1164
Test Recall	—	0.7198
Test F1	—	0.1676

The results demonstrate an important point:

Class weighting improved validation performance, but the improvement did not automatically translate into higher official test ROC-AUC.

This is why the project reports multiple evaluation metrics instead of relying on a single number.

🧪 Evaluation

MediFusion evaluates the model using multiple metrics.

ROC-AUC

Measures ranking ability across probability thresholds.

PR-AUC

Especially useful when dealing with highly imbalanced classes.

Precision

Measures how many predicted positives were actually positive.

Recall / Sensitivity

Measures how many actual positive samples were detected.

Specificity

Measures how well negative samples were identified.

F1 Score

Balances precision and recall.

⚠️ Current Limitations

MediFusion is a research prototype, not a clinically validated medical system.

Important limitations include:

The model is trained on a public research dataset.
Dataset labels may contain noise.
Performance varies substantially between pathologies.
Rare abnormalities have limited positive examples.
Probability scores should not be interpreted as clinical certainty.
The model has not undergone clinical validation.
The model has not been evaluated across diverse hospital populations.
No clinical deployment should be based on this prototype.

Therefore:

A predicted finding should be treated as an AI-generated research output rather than a diagnosis.
